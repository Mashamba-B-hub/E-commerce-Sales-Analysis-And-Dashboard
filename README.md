## E-commerce-Sales-Analysis-And-Dashboard

# Project Overview

This project involved analysing messy e-commerce sales data and transforming it into a clean dataset for business analysis and visualisation.

# Tools Used
Python
Pandas
VS Code and Jupyter Notebook
PostgreSQL
SQL
Power BI
Project Process

# 1. Data Cleaning with Python

I imported the raw e-commerce dataset into VS Code using Jupyter Notebook and Pandas. I inspected missing values, duplicate records, and inconsistent formatting. I cleaned the data by handling missing values, removing duplicates, standardising text, and formatting dates. I then saved the cleaned dataset as a CSV file.

# 2. PostgreSQL Database Integration

I connected Python to PostgreSQL and imported the cleaned CSV file into a table named cleaned_data. I verified the imported data using pgAdmin.

# 3. SQL Business Analysis

I used SQL queries to answer business questions, including:

Which country generated the highest sales?
Which products sold the most?
What was the total revenue?
How did sales change over time?
How many orders came from each country?

# 4. Power BI Dashboard

I connected PostgreSQL to Power BI and created measures using DAX. I developed KPI cards for total revenue, total orders, total products sold, total customers, and average order value. I also created visualisations for sales by country, customer, month, category, and top-selling products, along with interactive slicers for filtering the results.

# Key Skills Demonstrated

Python, Pandas, data cleaning, SQL querying, PostgreSQL database integration, DAX measures, KPI development, data visualisation, and business intelligence reporting.

# Project Outcome

The project demonstrates an end-to-end data analytics workflow, from cleaning raw data to querying a database and building an interactive Power BI dashboard to explore e-commerce sales performance and support data-driven business decisions.
